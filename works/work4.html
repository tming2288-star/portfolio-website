Works

ポートフォリオ

#Website自主制作

制作時期：2026年6月

概要

Web/Cloud Engineerとしての転職活動用に自主制作したポートフォリオサイト。自分自身がクライアントとなる自主制作案件。制作期間3週間で公開。

目的

クラウドエンジニアへの転職活動用ポートフォリオ。これまでのWebデザイナーとしての実績を示しつつ、AWS認定資格「AWS Certified Cloud Practitioner(CLF)」「AWS Certified Solutions Architect – Associate(SAA)」の取得によるクラウド分野への意欲・実力を採用担当者に伝えることを目的とする。本サイト自体もAWS上にホスティングして、実践的なクラウド運用スキルの証明も兼ねている。

ターゲット
  • 採用担当者
  • Web制作会社
  • フリーランス案件の発注者

これまで培ったデザイン力に加え、新たに習得したクラウドの知識・実装力を重視して見てもらいたいという狙いがあり、Skillsセクションの構成やサイト自体のホスティング環境にその意図を反映している。

情報設計

「ヒーロー→About me→Skills→Works→Contact」という流れで、まず人物像を印象づけた上で、スキル→実績の順に説得力を積み上げる構成。
Skillsセクションは「Cloud → Web → Tools → No-code/CMS」の順に配置。今後クラウドエンジニアとしての仕事を得たいという意図から、あえてCloudを最初に配置し、閲覧者の目に最初に留まるようにした。

デザイン

自身の誕生月(10月)にちなんだ、自分らしさを表す色として選定。ロゴは自身の名前ともみじの形を組み合わせてデザインし、秋のコンセプトと個人のアイデンティティを掛け合わせている。
手書き風フォントはAIやテンプレートではなく自分の手で一からコーディングした温かみ・親しみやすさを演出。
「この人と一緒に働くイメージ」を採用担当者に持ってもらえるよう、あえて大きく人物写真を配置。

制作範囲

ワイヤーフレーム設計からコーディング・公開まで一貫して自身で担当。

使用技術

HTML / CSS / jQuery / AWS(S3, CloudFront, Route53)

使用ツール

Dreamweaver(コーディング)、Illustrator・Photoshop・Canva(ビジュアル制作)
