Works

ポートフォリオ

#Website自主制作

制作時期：2026年6月

概要

Web/Cloud Engineerとしての転職活動用に自主制作したポートフォリオサイト。自分自身がクライアントとなる自主制作案件。制作期間3週間で公開。

目的

Webデザイナーとしての制作実績の公開、およびAWS環境を活用したサイト構築・運用を目的に作成いたしました。
これまで培ったデザイン・フロントエンド技術と、AWS資格（CLF /SAA）の学習で習得したインフラ・クラウド知識を組み合わせたポートフォリオサイトです。

ターゲット
  • 採用担当者
  • Web制作会社
  • フリーランス案件の発注者

デザイン面だけでなくクラウド技術の実装面も含めて確認できるよう、Skillsセクションの設計や、AWS（S3 / CloudFront）上でのホスティング構成に反映させています。

情報設計

「ヒーロー→About me→Skills→Works→Contact」という流れで、まず人物像を印象づけた上で、スキル→実績の順に説得力を積み上げる構成。
Skillsセクションは「Cloud → Web → Tools → No-code/CMS」の順に配置。今後クラウドエンジニアとしての仕事を得たいという意図から、あえてCloudを最初に配置し、閲覧者の目に最初に留まるようにした。

デザイン

秋（10月）をモチーフとしたカラーと、自身の名前ともみじの形状を組み合わせたロゴにより、個人のアイデンティティを表現しました。手書き風フォントを活かしたコーディングにより温かみや親しみやすさを演出し、採用担当者が「一緒に働くイメージ」を持ちやすいビジュアルおよびUI設計としています。

制作範囲

ワイヤーフレーム設計からコーディング・公開まで一貫して自身で担当。

使用技術

HTML / CSS / jQuery / AWS(S3, CloudFront, Route53)

使用ツール

Dreamweaver(コーディング)、Illustrator・Photoshop・Canva(ビジュアル制作)
